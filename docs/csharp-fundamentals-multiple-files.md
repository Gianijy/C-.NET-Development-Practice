# Using Multiple C# Files in One Console Project

Yes. A C# console project can contain **many `.cs` files**, and they are compiled together into one application.

## Recommended Project Structure

```text
C# Fundamentals/
├── Program.cs
├── C# Fundamentals.csproj
│
├── Basics/
│   ├── Variables.cs
│   ├── DataTypes.cs
│   └── UserInput.cs
│
├── ControlFlow/
│   ├── Conditionals.cs
│   ├── SwitchStatements.cs
│   └── Loops.cs
│
├── Methods/
│   ├── BasicMethods.cs
│   └── Parameters.cs
│
├── Collections/
│   ├── Arrays.cs
│   └── Lists.cs
│
├── ObjectOrientedProgramming/
│   ├── ClassesAndObjects.cs
│   └── Inheritance.cs
│
├── bin/
└── obj/
```

Modern .NET projects automatically include `.cs` files located inside the project directory and its subdirectories. You normally do not need to add each file manually to the `.csproj` file.

## Important: Use One Main Entry Point

Your current `Program.cs` probably contains top-level code such as:

```csharp
Console.WriteLine("Hello, World!");
```

This is the application's entry point. Avoid placing top-level executable code directly inside every `.cs` file.

For example, avoid writing this directly inside `Loops.cs`:

```csharp
for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);
}
```

Instead, place each topic inside a class and a method.

## Example: `Loops.cs`

Create this file inside `ControlFlow/Loops.cs`:

```csharp
namespace CSharpFundamentals.ControlFlow;

public static class Loops
{
    public static void Run()
    {
        for (int i = 1; i <= 5; i++)
        {
            Console.WriteLine(i);
        }
    }
}
```

## Example: `Variables.cs`

Create this file inside `Basics/Variables.cs`:

```csharp
namespace CSharpFundamentals.Basics;

public static class Variables
{
    public static void Run()
    {
        string name = "Gian";
        int age = 17;

        Console.WriteLine($"Name: {name}");
        Console.WriteLine($"Age: {age}");
    }
}
```

## Example: `UserInput.cs`

Create this file inside `Basics/UserInput.cs`:

```csharp
namespace CSharpFundamentals.Basics;

public static class UserInput
{
    public static void Run()
    {
        Console.Write("Enter your name: ");
        string? name = Console.ReadLine();

        Console.WriteLine($"Hello, {name}!");
    }
}
```

## Use `Program.cs` as the Lesson Menu

`Program.cs` can decide which lesson to run:

```csharp
using CSharpFundamentals.Basics;
using CSharpFundamentals.ControlFlow;

Console.WriteLine("Choose a topic:");
Console.WriteLine("1. Variables");
Console.WriteLine("2. Loops");
Console.WriteLine("3. User input");

Console.Write("Choice: ");
string? choice = Console.ReadLine();

switch (choice)
{
    case "1":
        Variables.Run();
        break;

    case "2":
        Loops.Run();
        break;

    case "3":
        UserInput.Run();
        break;

    default:
        Console.WriteLine("Invalid choice.");
        break;
}
```

## Run the Project

Run this command from the directory containing `C# Fundamentals.csproj`:

```bash
dotnet run
```

## C# File Naming Convention

C# file names normally use **PascalCase**:

```text
Loops.cs
Variables.cs
UserInput.cs
ConditionalStatements.cs
Methods.cs
Arrays.cs
```

This is preferred over names such as:

```text
loops.cs
variables.cs
userInput.cs
```

## Folders and Namespaces

Folders organize your files for humans. Namespaces organize types in your code.

For example:

```text
ControlFlow/Loops.cs
```

can use:

```csharp
namespace CSharpFundamentals.ControlFlow;
```

The folder and namespace do not have to match, but matching them is a useful convention.

## Important Notes

- Every `.cs` file in the project is compiled into the same console application.
- A folder does not create a separate application.
- Keep only one entry point, normally `Program.cs`.
- Do not put your own source code inside `bin/` or `obj/`.
- The `bin/` and `obj/` directories are generated by .NET.
- Add new folders only when you begin learning those topics.

## One Project Versus Multiple Projects

For now, this structure is appropriate:

```text
One project
→ one application
→ many .cs files
→ one entry point
```

Later, when exercises become larger or need to run independently, create separate projects rather than only separate folders:

```text
CSharpPractice/
├── VariablesPractice/
│   ├── VariablesPractice.csproj
│   └── Program.cs
├── LoopsPractice/
│   ├── LoopsPractice.csproj
│   └── Program.cs
└── MethodsPractice/
    ├── MethodsPractice.csproj
    └── Program.cs
```

For your current learning stage, use **one project, organized topic folders, and one `Program.cs` menu**.
